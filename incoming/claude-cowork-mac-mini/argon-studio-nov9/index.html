    The 12 Open-Source Fun Principles

    1. One-sentence core loop — clear & immediate.
    2. Playable in 5 seconds — first input on screen 1.
    3. Consequential tradeoffs — competing uses of scarce resources.
    4. Visible world feedback — bottlenecks, flow & juice.
    5. Short goal + long goal — clear milestone + endless mastery.
    6. Tunable difficulty curve — fast ramp, smooth cap.
    7. Familiar genre + one twist — fresh spatial/system tension.
    8. Progressive reveal — new capabilities unlock new verbs.
    9. Honest explanations — recaps trace directly to logged events.
    10. Short runs, permanent learning — mistakes teach strategy.
    11. Versioned local persistence — reload never double-rewards.
    12. Pure simulation boundary — deterministic seeded RNG.
