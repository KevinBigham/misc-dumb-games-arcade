LAST BELL: THE SCHOOL STORE CHALLENGE
Version 1.0

1. Unzip the folder.
2. Open Teacher_Guide.pdf. The first page covers setup and timing.
3. Print Student_Sheets.pdf (two pages per student).
4. Open Last_Bell.html in a desktop browser. Choose the number of teams.
5. Read each forecast. Have every team lock a price and stock choice on paper.
6. Reveal demand. Let students calculate. Then check the results on screen.

If your school blocks HTML files, use Projector_Deck.pdf instead. It has every
forecast and demand reveal, and the teacher guide has all possible profits.
The paper version is a complete lesson.

WHAT IS INCLUDED
- Last_Bell.html: four-round teacher game with automatic scoring.
- Student_Sheets.pdf: two-page student record and individual exit ticket.
- Teacher_Guide.pdf: five-page setup guide, answer key, and adaptations.
- Projector_Deck.pdf: twelve black-background projection pages.

ACCESS AND SAVES
No student accounts. No network requests. No tracking. No external software
libraries. The game is intended for a teacher's desktop browser, projected
for the class. iPad and school-managed Chromebook file handling may vary;
use the PDFs if the file will not open. Do not assume a cloud-drive preview
will execute the game. Download and open the HTML file.

The browser tries to save progress locally. Save session downloads a JSON
backup; Load session restores it. Export results downloads anonymous CSV
results by team letter. New class clears the current session after a prompt.

The scenarios are fixed teaching models. They do not model student teams
competing for the same customers, real-world demand, labor, or taxes.
The answer values are included in the file; keep it on the teacher's screen.
