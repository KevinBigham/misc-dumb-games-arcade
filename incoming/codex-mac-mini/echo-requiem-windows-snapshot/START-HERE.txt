ECHO REQUIEM v0.1.0 — Kevin's private playable copy

Jump back. Leave yourself fighting.
A temporal arena shooter with three acts, upgrades, procedural audio and a boss.

WINDOWS LAUNCH
1. Download this ZIP and choose Extract All. Do not run files inside the ZIP viewer.
2. This original game launcher requires an already installed Node.js 22 or newer.
   No npm install, dependency download, account or game build is required.
3. Double-click Play-Windows.cmd. Keep its command window open while playing.
4. It opens your default browser at http://localhost:4173. Chrome or Edge is recommended.
   If the browser does not open automatically, enter that address yourself.
5. Click Play to enable audio. Close the browser tab and press Ctrl+C in the server
   window when finished.

Do NOT double-click index.html: the game uses native JavaScript modules and needs HTTP.
This package does not install Node.js. If Node.js 22+ is absent, the launcher reports it.
If port 4173 is occupied, open a terminal in this extracted folder and run:
  node scripts/serve.mjs --port 4174
Then visit http://localhost:4174.

CONTROLS
WASD: move. Mouse + hold left click: aim/fire.
Space / E / right click: Fork time and leave a shooting echo.
Shift: dash. Escape: pause/resume. M: mute. 1/2/3: choose upgrade.
R on the result screen: retry the same seed.
