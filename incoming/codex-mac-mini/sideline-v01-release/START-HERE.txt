SIDELINE - Franchise Football

Requires Node.js 22+ and a browser. No installation or internet needed.

macOS: open Play.command.
All platforms: in this folder, run npm run dev, then visit http://localhost:4173.
If that port is occupied: npm run dev -- --port 4175.

Choose Settings > Create new franchise to select your team.
Use Settings > Export franchise to back up or move your save.
Saves are tied to the browser and port.

Original 32-team football league. Manage personnel, coaching, finances,
weekly games, playoffs, and a seven-round draft across multiple seasons.
This first release uses drive-level simulation, not on-field control.

Echo Requiem remains available at /echo.html.
