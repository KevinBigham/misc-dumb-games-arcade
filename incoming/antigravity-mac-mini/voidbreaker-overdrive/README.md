# ⚡ VOIDBREAKER: OVERDRIVE

**A High-Octane Cyber-Mech Twin-Stick Action Roguelite & Bullet-Heaven Boss-Rush Game**

Built with TypeScript, HTML5 Canvas (Additive HDR Glow & Hooke's Law Warping Geometry Grid), Native Top-Layer Web UI (`<dialog>`, `@starting-style`, Invoker Commands), and a 100% Procedural WebAudio Dark-Synthwave Sequencer & SFX Studio.

---

## 🎮 Key Combat Systems

1. **Three Playable Cyber-Frames**:
   - **STRIKER-09 `VALKYRIE`**: High-speed twin pulse repeaters + **Plasma Katana Arc** that cleaves enemies and **deflects enemy projectiles back at 350% damage**.
   - **TITAN-X `HELLFORGE`**: Spooling rotary vulcan autocannon + **Singularity Mortar** that warps the spacetime grid into a crushing black hole.
   - **SPECTRE-7 `CHRONOS`**: Hyper-velocity piercing railgun + **Chrono-Stasis Dome** & autonomous orbital drones.
2. **Tachyon Witch-Time (Perfect Phase-Dash)**:
   - Dash (`Space` / `Shift`) *through* incoming enemy bullets at the last split-second to trigger **2.6+ seconds of global bullet-time slow-motion** while boosting your Mech's speed and Ultimate charge.
3. **Active Thermal Venting (`[R]`)**:
   - Firing builds thermal core heat. Press `R` while the heat bar is inside the cyan **65%–80% Sweet Spot** to instantly vent all heat and gain **4.5 seconds of 100%-Crit Overcharge**!
4. **24 Neural Augments & 6 Weapon Synergy Evolutions**:
   - Combine matching augments during a run to unlock devastating evolutions like **STORMBRINGER OVERLOAD**, **EVENT HORIZON GRINDER**, and **PHANTOM BLADE PROTOCOL**.
5. **3 Multi-Phase Sector Bosses**:
   - **Sector 01**: `SERAPH-MKIV` (Orbital Defense Core with sweeping twin lasers & spiral curtains)
   - **Sector 02**: `LEVIATHAN-OMEGA` (10-segment articulated Cyber-Wyrm)
   - **Sector 03**: `ARCHITECT PRIME` (Singularity Sovereign with quad cross-lasers & gravity implosions)

## 🕹️ Controls

| Input | Action |
| :--- | :--- |
| `WASD` / `Arrow Keys` / `Left Stick` | Move Cyber-Frame |
| `Mouse Cursor` / `C` Toggle | Aim (or toggle Autonomous Target Lock) |
| `Left Click` / `F` Toggle | Fire Primary Weapon (or toggle Auto-Fire) |
| `Right Click` / `E` | Fire Alt-Weapon / Plasma Katana Bullet Parry |
| `Space` / `Shift` | Phase Dash (graze bullets to trigger **Witch-Time**) |
| `R` | Active Thermal Vent (hit the cyan Sweet-Spot for **Overcharge**) |
| `Q` | Unleash Ultimate Overclock (at 100% charge) |
| `1` / `2` / `3` | Quick-select Neural Augment on Level-Up |
| `Esc` / `P` | Open Orbital Mech Hangar / Pause |
